# 物流追踪自动化项目 - 项目概述与业务背景

## 1. 业务背景

公司"唯镜"是一家跨境电商企业，通过 Amazon FBA（Fulfillment by Amazon）进行销售。物流部门需要持续追踪从中国发往全球 Amazon 仓库的货件状态，涉及 **8 家不同的货代（freight forwarder）**。

## 2. 完整工作流程

```
1. 人工从钉钉群下载最新 Excel 文件（发货流程表）到本地
2. 运行本程序：
   a. 从 Excel 读取所有货件数据 → 导入 PostgreSQL 数据库
   b. 对每个未签收且有货运单号的货件，爬取对应货代的物流状态
   c. 对比新旧状态，有变化时发钉钉私聊通知负责人
   d. 分析异常（延期/查验/延误），汇总发送钉钉通知
   e. 将更新后的数据写回 Excel 文件
3. 人工将更新后的 Excel 上传至钉钉群覆盖原文件
```

## 3. 关键约束

- **Excel 是唯一数据源**：每次运行前从钉钉下载最新版，程序运行期间不会有编辑改动
- **数据库仅作为临时缓存**：不需要持久化，每次运行全量重建
- **钉钉未企业认证**：无法通过 API 下载/上传 Excel 文件，需人工操作或使用桌面自动化（`dingtalk_automation.py`）

## 4. 技术栈

| 技术 | 用途 |
|------|------|
| Python 3.9+ | 开发语言 |
| Playwright | 浏览器自动化（5 家货代网站爬取） |
| PostgreSQL | 临时数据缓存 |
| 钉钉机器人 API | 状态变更和异常通知 |
| pandas + openpyxl | Excel 读写 |
| requests | HTTP 请求（钉钉 API、纽酷 API） |
| pywinauto + pyautogui | 钉钉桌面自动化（`dingtalk_automation.py`） |
